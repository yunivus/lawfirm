# LexCounsel interface recreation

Static responsive front-end recreated from the supplied composite reference.

## Pages
- index.html — public landing page
- login.html — sign-in
- intake.html — new client intake
- dashboard.html — client portal dashboard
- new-case.html — start a new case
- case-detail.html — case overview
- clients.html — client management
- cases.html — case management
- documents.html — document management
- settings.html — account/settings

## Run
Open `index.html` in a browser. All pages share `styles.css` and `script.js`.

No framework or build step is required. Demo interactions include navigation, mobile sidebar, form feedback, tabs, search filtering, and action toasts.
