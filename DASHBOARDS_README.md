# LexCounsel Role Dashboards

Added three separate role-based dashboard prototypes:
- `manager-dashboard.html` with `manager-dashboard.css` and `manager-dashboard.js`
- `lawyer-dashboard.html` with `lawyer-dashboard.css` and `lawyer-dashboard.js`
- `admin-dashboard.html` with `admin-dashboard.css` and `admin-dashboard.js`

The dashboards follow the existing LexCounsel navy/gold visual language, typography, spacing, responsive behavior, and interaction patterns. They are static front-end prototypes; connect buttons and data to the application backend/API for production use.
